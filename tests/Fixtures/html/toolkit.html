Healthcare Root Cause Analysis Toolkit

A simple offline practice tool for documenting an event, identifying contributing factors, testing root causes, and defining corrective actions.

1. Define the Event

Describe what happened objectively. Avoid blame, assumptions, or conclusions at this stage.

2. Build a Simple Timeline

Record the key sequence of events. Focus on what occurred before, during, and after the incident.

3. Explore Contributing Factors

A contributing factor is not automatically a root cause. Look for system conditions that allowed the event to occur or made it more likely.

4. Test a Cause with the Five Whys

Stop when the answer identifies a controllable system issue and further questioning no longer adds useful causal information.
